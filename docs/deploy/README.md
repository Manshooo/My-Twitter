# Сервер: что и в каком порядке

Каждый файл в этой папке — инструкция для одного шага. Здесь — порядок. Отправная точка — сервер на
uWSGI с кодом в `/var/www/azzb` (этапы 0–3, коммит `a9c244d`).

## Уже сделано

- PostgreSQL вместо SQLite — [postgres.md](postgres.md).
- Почта: Postfix, DKIM, SPF, DMARC `quarantine` — [mail.md](mail.md).
- Картинки на диске — [media.md](media.md); после шага 3 картинки переезжают в бакет.
- Выкладка этапа 3 — [stage3.md](stage3.md).

Проверить, что все миграции применены (пусто — значит, всё на месте):

```bash
cd /var/www/azzb && venv/bin/python manage.py showmigrations | grep '\[ \]'
```

## 1. Debian 12 — до конца (сейчас, 10 минут)

[debian13.md](debian13.md), раздел 0: обновить пакеты и перезагрузиться на новое ядро. От остального
не зависит.

## 2. Безопасность (сейчас)

[security.md](security.md):
- раздел 3 — ключи SmartCaptcha в `.env`;
- раздел 5 — HTTPS и HSTS, если ещё не включены.

Раздел 2 (`X-Real-IP`) уже есть в конфиге nginx для Docker, шаг 3 его принесёт. Раздел 6 (зависимости
в `venv`) после Docker не нужен.

## 3. Переезд на Docker (полдня, без простоя)

[docker.md](docker.md), разделы 1–8 по порядку: GitHub и раннер, `/srv/azzb`, бакеты Selectel,
картинки в бакет, контейнер рядом с uWSGI, переключение nginx, выключение uWSGI и новый cron
(копии и `purge_expired`, см. [retention.md](retention.md)).

`deploy.sh` выкладывает текущий `main` и сам применяет миграции всего, что вышло после `a9c244d`:
DM, уведомления «Опрос завершён», SEO, сеансы на устройствах и т. д. Отдельно `git pull` и `migrate`
делать не нужно. Через неделю — удалить старое (конец раздела 8).

## 4. После первой выкладки в Docker

- Поиск: `https://azzb.ru/sitemap.xml` в Яндекс Вебмастер и Google Search Console — [../seo.md](../seo.md).
- PWA: DevTools → Application, воркер `/sw.js` активен — [../pwa.md](../pwa.md).
- Метрика: номер счётчика в `YANDEX_METRIKA_ID`, затем проверить консоль браузера на CSP —
  [security.md](security.md), раздел 7.
- Письмо о входе с нового устройства: войти из другого браузера, письмо должно прийти.

## 5. Debian 13 (когда будет время, 1–2 часа)

[debian13.md](debian13.md), разделы 1–7, без раздела 6 (Python сайта живёт в образе). После
Docker это проще: на хосте остаются только nginx, PostgreSQL и Postfix.

## 6. Тариф 2 ГБ, затем реальное время

[realtime.md](realtime.md): `COMPOSE_PROFILES=realtime` и `REDIS_URL` в `.env`, блок `/ws/` в nginx.
До этого всё работает опросом.

## Вне сервера

Вычитка правил и политик юристом, регистрация оператора данных, если она требуется, — см.
[ROADMAP](../ROADMAP.md), «Что осталось вне кода».
