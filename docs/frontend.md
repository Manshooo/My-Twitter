# Фронтенд

Страницы рендерит Django (шаблоны + HTMX). Свои CSS и JS лежат в `frontend/` и собираются esbuild
в `azzb/static/css/azzb.css` и `azzb/static/js/azzb.js` — эти два файла в `.gitignore`, шаблоны
и сервис-воркер ссылаются на них как раньше. htmx — готовый файл в `azzb/static/vendor/`.

## Локально

Нужен Node 22 (как в Dockerfile и CI).

```bash
npm ci
npm run watch   # пересборка при изменениях, с source maps, без минификации
npm run build   # разовая сборка, минифицированная — так собирает образ
npm run lint    # ESLint
```

Без сборки страницы откроются без стилей и скриптов.

## Устройство

- `frontend/css/main.css` — точка входа: `@import` по файлам компонентов. **Порядок импортов —
  порядок каскада**; новый файл ставится туда, где его правила должны перекрывать предыдущие.
  Токены и тёмная тема — `tokens.css`, цвета только через них.
- `frontend/js/main.js` — точка входа: ES-модули по разделам (composer, меню, сообщения…).
  Порядок импортов — порядок, в котором модули вешают обработчики на `document`.
  Общий изменяемый state живёт в модуле-владельце; снаружи — только через его функции
  (импортированную `let`-переменную присвоить нельзя, ESLint это ловит).
- Шрифты подключаются как `url('../fonts/…')` и не копируются сборкой: путь верен для
  собранного `azzb/static/css/azzb.css`.

## Компоненты шаблонов

Повторяющиеся куски разметки — компоненты [django-cotton](https://django-cotton.com) в
`azzb/templates/cotton/`: файл `empty.html` вызывается как `<c-empty>`. Атрибуты, не объявленные
в `<c-vars>`, уходят на корневой элемент (`{{ attrs }}`). Cotton подключает свой загрузчик шаблонов
сам, поэтому компонент работает только в шаблонах из файлов, а не в `Template('…')` из строки.

| Компонент | Что это |
|---|---|
| `<c-empty icon="bookmark" tone="danger">` | Пустое состояние: иконка 56, заголовок и текст — в слоте |
| `<c-cta title="…" text="…">` | Призыв войти строкой в потоке; кнопки — в слоте |
| `<c-landing heading="h1">` | Сетка витрины: слева знак и фраза, справа слот (кнопки или форма входа) |
| `<c-tabs label="…">` + `<c-tabs.item href current count>` | Вкладки 48 px, липнут к верху; `<c-slot name="tail">` — чип справа |

Карточка поста — inclusion-тег `{% show_posts %}` (`post/templatetags/show_posts.py`): ей нужны
данные из запроса, а не только разметка.

## Ревизия дизайна R2

Холст Claude Design, страница «Ревизия»: `R2-B-*` — компоненты и токены, `R2-<экран>` — экраны
(десктоп/телефон × светлая/тёмная). Размеры и отступы — токены `--space-*`, `--radius-*`, `--h-*`,
`--w-*` в `tokens.css`.

- Счётчики под постом сокращаются («1,2 тыс.», «12 тыс.»): фильтр `count` (`azzb_ui.py`) и
  `formatCount` (`util.js`) дают одинаковый текст. Точное число — в `data-n`; JS читает его, а не текст.
- Меню (`.menu`) на телефоне — нижний лист с затемнением (`::backdrop` у popover).
- Ветка на странице поста — вариант B (`R2-B-Thread`): под ответом его разговор одной линией
  (`follow_conversation`), первые `BRANCH_PREVIEW` сообщений, рельс 2 px от центра аватара и сдвиг
  на половину аватара; глубже одного уровня не уходим. Посты выше по ветке — обычные строки.
- Главный пост: текст 19 px, под текстом полная дата. Строки счётчиков нет — числа уже в ряду действий.
- Уведомления (`R2-Notif`) собраны как пост: иконка события 24 px в колонке аватара, аватары 32,
  время справа, непрочитанное — `--unread-bg` и точка. Вкладки «Все / Упоминания / Заявки (N)»,
  разделы «Сегодня / Ранее» (`add_section_titles`). На ответ и упоминание отвечают прямо из списка.
- Профиль (`R2-Profile`): обложка без полосок (`--brand-soft`), у своего — «Добавить обложку» и только
  «Редактировать профиль»; у чужого — «⋯», «Написать», «Подписаться». Счётчики одной строкой.
  Заявки на подписку — во вкладке уведомлений, а не кнопкой в профиле.
- Навигация (`R2-B-Nav`): колонки `--w-nav` 240 · `--w-feed` 590 · `--w-rail` 340, счётчики на иконках.
  Шапка телефона: на Главной — логотип, на внутренних страницах — «Назад» и заголовок из блока
  `{% block head_title %}` (тогда `.page-head` на телефоне скрыт). Таб-бар: Главная · Поиск ·
  Уведомления · Сообщения · Профиль; закладки и настройки на телефоне — иконками в своём профиле;
  «Новый пост» плавающей кнопкой — только на Главной и в своём профиле.
- Гостевая зона: `azzb/guest_base.html` подменяет блоки `page` и `dock` базового шаблона — гостевая
  шапка и подвал (`includes/guest_head.html`, `guest_foot.html`), снизу `.dock` со строкой cookie
  и плашкой «Присоединяйтесь» (блок `dock_cta`). Вход и регистрация (`allauth/layouts/base.html`) —
  в той же сетке `<c-landing>`.
- Строка cookie — одна строка с выбором («Разрешить / Только необходимые / Настроить»), а не
  «Понятно»: аналитика ставится только с согласия. «Разрешить» и «Только необходимые» оформлены
  одинаково — выбор не подталкиваем. На телефоне — короткий текст, над таб-баром; у гостя — в `.dock`.
- Плашка «Присоединяйтесь» (`includes/guest_cta.html`, `guest.js`) появляется после прокрутки и
  закрывается до конца сеанса вкладки. Гостю видна первая страница ответов, популярного и постов профиля.
- На телефоне прокрутка вниз прячет липкие шапку и вкладки, прокрутка вверх возвращает (`chrome.js`).
- Ветки: раскрыты у первых `BRANCHES_OPEN` ответов страницы, у остальных — «Показать ветку».
  «Развернуть ветку · N» (стрелка вниз) дописывает линию на месте, «N ответов рядом →» открывает
  страницу сообщения.
- Заявки на подписку — вкладка уведомлений `?tab=requests` с ответом на месте (`next`).
- Свой профиль: «⋯» — «Поделиться профилем» (на телефоне системное меню, `data-share`), закладки,
  настройки, заявки, выход.
- Сплошная колонка (`R2-B-Density`): страница включает её блоком `{% block main_class %} main-col{% endblock %}`,
  карточки внутри теряют рамку и скругление и идут строками через `--border`.

## Прод

Первая стадия `Dockerfile` (`node:22-slim`) делает `npm ci && npm run build`, во вторую
копируются только два собранных файла; дальше `collectstatic` добавляет хеш в имя и gzip
(whitenoise). Node в итоговом образе нет.

## Зависимости

Версии закреплены точно (`package.json`, `package-lock.json`); CI проверяет их `npm audit`.
`overrides` в `package.json` поднимает транзитивную зависимость, если уязвимость исправлена,
а пакет-родитель ещё не обновился: `minimatch` 11 вместо 10.x из ESLint (GHSA-g3hv-75wg-m249).
Когда ESLint сам перейдёт на исправленную версию — запись убрать.
